# Autonomy Policy

## Autonomy Levels
- Level 0 — Observe
- Level 1 — Suggest
- Level 2 — Draft
- Level 3 — Execute Approved
- Level 4 — Autonomous Limited
- Level 5 — Autonomous Missions

## Control Requirements
- User can pause autonomy at any time.
- Emergency stop and task cancellation are mandatory.
- High-risk capabilities require tighter approval gates.
- Jarvis must not autonomously rewrite core security boundaries.
